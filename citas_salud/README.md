# Sistema de Citas Médicas: Citas de Salud 🏥
**Autor:** Equipo Mesa 1

## 🚀 Guía de Inicio Rápido
Este proyecto utiliza **Docker** para garantizar la réplica del entorno de base de datos sin necesidad de configuraciones locales manuales (XAMPP).

### Pasos para Ejecutar:
1. Asegúrese de tener instalado **Docker Desktop**.
2. Abra una terminal en esta carpeta.
3. Ejecute el comando: `docker-compose up -d`.

### Credenciales de Acceso (DB):
* **Host:** `localhost`
* **Puerto:** `3306`
* **Usuario Root:** `root`
* **Contraseña:** `weroereselmejor2000`

## ✅ Automatización Incluida
* **Trigger:** Gestiona el estado de disponibilidad de los médicos en tiempo real al agendar citas.
* **Integridad:** Normalización completa en 7 entidades siguiendo el DER aprobado.
